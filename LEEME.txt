MINIMARKET JS - WINDOWS V8 - CAJA RAPIDA, INVENTARIO Y RECUPERACION
Windows 10/11 de 64 bits. Instancia completa con DATOS FICTICIOS.

ABRIR SIN PROGRAMAR
1. Cierra la demostracion anterior y conserva una copia de su carpeta completa.
2. Extrae TODO este ZIP en una carpeta nueva.
3. En MINIMARKET-JS haz doble clic en ABRIR-MINIMARKET.cmd.
4. Espera la primera preparacion con Internet. No cierres la ventana.
5. Se abren navegador y ACCESO.txt. Usa el correo y clave de ese archivo.
Conserva el iniciador Windows ya probado por el usuario. PostgreSQL incluido y extraido, sin XZ.
No requiere instalar Node.js, PostgreSQL o Docker por separado.

BIENVENIDA Y BIBLIOTECA

PROBAR TICKETS
- Menu Ventas y Caja: escanea 000000001008 y Enter, ingresa 10000 para compra de 7350.
- Teclado numerico, Monto exacto y montos rapidos; falta de efectivo bloquea Cobrar.
- Veras vuelto de 2650. Cobrar guarda la venta una sola vez y descuenta stock.
- Despues: Imprimir / reimprimir ticket, o Vista previa del ticket.
- Tambien abre ventas recientes -> Ver e imprimir ticket.
- Elegir 58/80 mm. El dialogo de Edge/Chrome permite elegir la impresora o Guardar como PDF.
- Si no hay impresora o cancelas, la venta sigue guardada. Reimprimir no vuelve a cobrar.
- Hay un ticket ficticio ya registrado para revisar sin hacer otra venta.
- Impresoras y tickets -> Pagina de prueba no registra una venta.
- Los intentos de impresion se auditan como SOLICITUD, no confirman papel impreso.
- Ticket INTERNO: NO ES BOLETA NI FACTURA TRIBUTARIA SII.

IMPORTACION EXCEL

- Actualizar precios existentes requiere vista previa y confirmacion. Una celda vacia conserva el precio.

El paquete no contiene proveedores, contactos, ventas ni documentos reales del negocio.
Solo la instancia privada de la nube conserva el directorio real. No se traslada publicamente.
Google y WhatsApp real siguen pendientes de credenciales. No se envian mensajes externos.
PedidosYa sigue desconectado. No se procesan tarjetas, bancos ni documentos fiscales.
No se ha probado una impresora fisica. Ver GUIA-TICKETS.md para Windows y alternativa ESC/POS.

CONSERVAR TUS PRUEBAS
La base esta en .local de cada carpeta; no la borres. Cierra la anterior antes de abrir esta.
Carpeta nueva no copia tus movimientos previos. Conserva completa la carpeta anterior.
Para actualizar: primero respaldar TODA la carpeta y detener el servidor; conservar .local,
ACCESO.txt y comprobantes al reemplazar archivos. Las migraciones no vuelven a sembrar datos.
El logo cargado y configuracion de mensajes permanecen en la base de esa carpeta.

ACTUALIZAR CONSERVANDO LOGO, CUENTAS Y MOVIMIENTOS
1. En la ventana negra del iniciador anterior pulsa Ctrl+C y espera que se cierre.
2. Guarda una COPIA COMPLETA de tu carpeta anterior; no la borres.
3. Extrae este ZIP en otra carpeta.
4. En el Explorador de Windows activa Vista -> Elementos ocultos.
5. Copia desde la anterior a la nueva la carpeta .local, el archivo ACCESO.txt y
   la carpeta comprobantes-demo. Reemplaza esos archivos en la carpeta NUEVA.
6. En la nueva haz doble clic en ABRIR-MINIMARKET.cmd y espera la actualizacion.
La base y tu logo estan en .local. No copies solo el PNG: conserva la carpeta completa.
Si prefieres probar desde cero, no copies nada y conserva la anterior completa para volver.
